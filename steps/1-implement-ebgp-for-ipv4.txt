PRACTICAL 1: Implement eBGP for IPv4
====================================

IP PLAN (subnet mask 255.255.255.0 everywhere)
  PC0        IP 198.123.1.2    Gateway 198.123.1.1
  PC1        IP 198.123.3.2    Gateway 198.123.3.1
  Router0    FastEthernet0/0  198.123.1.1     Serial2/0  198.123.2.1   (AS 100)
  Router1    FastEthernet0/0  198.123.3.1     Serial2/0  198.123.2.2   (AS 200)

1. BUILD THE TOPOLOGY
   - Routers (bottom left) -> drag 2 Router-PT onto the workspace
   - End Devices -> drag 2 PCs
   - Connections -> Automatic -> click PC0, then Router0. Repeat PC1 -> Router1
   - Connections -> Serial DCE (red zigzag) -> click Router0 (Serial2/0), then Router1 (Serial2/0)
   - Wait until the link dots turn green

2. SET THE PC IPs
   - Click PC0 -> Config -> FastEthernet0
   - IP Configuration: Static
   - IPv4 Address 198.123.1.2, Subnet Mask 255.255.255.0
   - Config -> Settings (under GLOBAL) -> Default Gateway 198.123.1.1
   - Click PC1 and repeat: IP 198.123.3.2, mask 255.255.255.0, gateway 198.123.3.1
   - (Same can be done from Desktop -> IP Configuration)

3. SET THE ROUTER INTERFACE IPs
   - Click Router0 -> Config -> FastEthernet0/0
   - Port Status On, IPv4 Address 198.123.1.1, Subnet Mask 255.255.255.0
   - Serial2/0 -> Port Status On, IPv4 Address 198.123.2.1, Subnet Mask 255.255.255.0
   - Click Router1 -> Config -> FastEthernet0/0
   - Port Status On, IPv4 Address 198.123.3.1, Subnet Mask 255.255.255.0
   - Serial2/0 -> Port Status On, IPv4 Address 198.123.2.2, Subnet Mask 255.255.255.0
   - Hover the serial cable to find the router with the clock icon (DCE)
   - On that router's Serial2/0, set Clock Rate to 64000

4. CONFIGURE BGP (router -> CLI tab -> press Enter)

   Router0:
     enable
     conf t
     router bgp 100
     network 198.123.1.0
     network 198.123.2.0
     neighbor 198.123.2.2 remote-as 200
     end

   Router1:
     enable
     conf t
     router bgp 200
     network 198.123.3.0
     network 198.123.2.0
     neighbor 198.123.2.1 remote-as 100
     end

   - Expect: %BGP-5-ADJCHANGE: neighbor ... Up
   - Close the CLI window with the red X when done (config stays on the router)

5. VERIFY
   - On a router, at the Router# prompt (type "end" first if in config mode):
       show ip bgp summary
       show ip route
   - Neighbor shows a number in PfxRcd, and a "B" route appears in the route table
   - PC0 -> Desktop -> Command Prompt:
       ping 198.123.3.2
   - Check the first number is 198, not 192
   - First ping may time out, run it again; replies mean eBGP works
