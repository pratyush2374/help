PRACTICAL 3: Implement OSPF using Multi Area
============================================

IP PLAN
  Laptop0   IP 192.168.1.2   Gateway 192.168.1.1   (mask 255.255.255.0)
  Laptop1   IP 192.168.2.2   Gateway 192.168.2.1   (mask 255.255.255.0)
  Router0   Fa0/0 10.10.10.1 (255.255.255.252)    Fa0/1 192.168.1.1 (255.255.255.0)
  Router1   Fa0/0 10.10.10.2 (255.255.255.252)    Fa0/1 10.101.10.1 (255.255.255.252)
  Router2   Fa0/0 10.101.10.2 (255.255.255.252)   Fa0/1 192.168.2.1 (255.255.255.0)
  Area 0: Router0 side     Area 1: Router2 side     Router1 = ABR (one interface in each)
  OSPF process id: 24222

1. BUILD THE TOPOLOGY
   - Routers -> drag 3 routers of type 1841
   - End Devices -> drag 2 Laptop-PT
   - Connections -> Automatic -> click Router0 (FastEthernet0/0), then Router1 (FastEthernet0/0)
   - Click Router1 (FastEthernet0/1), then Router2 (FastEthernet0/0)
   - Click Laptop0, then Router0 (FastEthernet0/1)
   - Click Laptop1, then Router2 (FastEthernet0/1)
   - Wait for the link dots to turn green

2. SET THE LAPTOP IPs
   - Click Laptop0 -> Config -> FastEthernet0
   - IPv4 Address 192.168.1.2, Subnet Mask 255.255.255.0
   - Config -> Settings -> Default Gateway 192.168.1.1
   - Click Laptop1 and repeat: IP 192.168.2.2, mask 255.255.255.0, gateway 192.168.2.1

3. CONFIGURE ROUTER INTERFACES (router -> CLI tab -> press Enter)
   - If it asks "initial configuration dialog?", type: no

   Router0:
     enable
     conf t
     int fa0/0
     ip add 10.10.10.1 255.255.255.252
     no shut
     exit
     int fa0/1
     ip add 192.168.1.1 255.255.255.0
     no shut
     exit
     exit
     wr

   Router1:
     enable
     conf t
     int fa0/0
     ip add 10.10.10.2 255.255.255.252
     no shut
     exit
     int fa0/1
     ip add 10.101.10.1 255.255.255.252
     no shut
     exit
     exit
     wr

   Router2:
     enable
     conf t
     int fa0/0
     ip add 10.101.10.2 255.255.255.252
     no shut
     exit
     int fa0/1
     ip add 192.168.2.1 255.255.255.0
     no shut
     exit
     exit
     wr

4. CONFIGURE OSPF

   Router0 (Area 0):
     conf t
     router ospf 24222
     network 10.10.10.0 0.0.0.3 area 0
     network 192.168.1.0 0.0.0.255 area 0
     end

   Router1 (ABR):
     conf t
     router ospf 24222
     network 10.10.10.0 0.0.0.3 area 0
     network 10.101.10.0 0.0.0.3 area 1
     end

   Router2 (Area 1):
     conf t
     router ospf 24222
     network 10.101.10.0 0.0.0.3 area 1
     network 192.168.2.0 0.0.0.255 area 1
     end

   - Expect: %OSPF-5-ADJCHG ... from LOADING to FULL

5. CHECK CONNECTIVITY
   - On each router, at the Router# prompt:
       show ip route ospf
       show ip ospf neighbor
   - Router0 and Router2 show "O IA" (inter-area) routes learned through Router1
   - Neighbors show FULL
   - Laptop0 -> Desktop -> Command Prompt:
       ping 192.168.2.2
   - First ping may time out, run it again; replies mean multi-area OSPF works
