PRACTICAL 2: Implement Single Area OSPF
=======================================

IP PLAN
  Router0   Loopback0 10.10.20.1 (255.255.255.0)   Fa0/0 192.168.0.2 (255.255.255.0)
  Router1   Loopback0 10.10.10.1 (255.255.255.0)   Fa0/0 192.168.0.1 (255.255.255.0)
  Router2   Loopback0 10.10.30.1 (255.255.255.0)   Fa0/0 192.168.0.3 (255.255.255.0)
            Serial0/1/0 172.16.0.1 (255.255.255.252)
  Router3   Loopback0 10.10.40.1 (255.255.255.0)
            Serial0/1/0 172.16.0.2 (255.255.255.252)
  Router IDs: R0 10.2.2.2, R1 10.1.1.1, R2 10.3.3.3, R3 10.4.4.4
  Router0, Router1, Router2 connect to Switch0 (LAN 192.168.0.0)
  Router2 to Router3 over serial (172.16.0.0)

1. BUILD THE TOPOLOGY
   - Routers -> drag 4 routers of type 1841
   - Switches -> drag 1 switch 2950-24
   - Click Router2 -> Physical -> switch it off (power button)
   - Drag HWIC-2T into an empty slot, switch it back on
   - Repeat the same for Router3
   - Connections -> Automatic -> click Router0, then Switch0
   - Repeat for Router1 -> Switch0 and Router2 -> Switch0
   - Connections -> Serial DCE (red zigzag) -> click Router2 (Serial0/1/0), then Router3 (Serial0/1/0)
   - Wait for the link dots to turn green

2. CONFIGURE INTERFACES (router -> CLI tab -> press Enter)
   - If it asks "initial configuration dialog?", type: no
   - Only type commands at the Router# / Router(config)# prompts

   Router0:
     enable
     conf t
     int loopback 0
     ip add 10.10.20.1 255.255.255.0
     no shut
     exit
     int fa0/0
     ip add 192.168.0.2 255.255.255.0
     no shut
     exit

   Router1:
     enable
     conf t
     int loopback 0
     ip add 10.10.10.1 255.255.255.0
     no shut
     exit
     int fa0/0
     ip add 192.168.0.1 255.255.255.0
     no shut
     exit

   Router2:
     enable
     conf t
     int loopback 0
     ip add 10.10.30.1 255.255.255.0
     no shut
     exit
     int serial0/1/0
     ip add 172.16.0.1 255.255.255.252
     clock rate 64000
     no shut
     exit
     int fa0/0
     ip add 192.168.0.3 255.255.255.0
     no shut
     exit

   Router3:
     enable
     conf t
     int loopback 0
     ip add 10.10.40.1 255.255.255.0
     no shut
     exit
     int serial0/1/0
     ip add 172.16.0.2 255.255.255.252
     no shut
     exit

   - Clock rate goes on the router with the clock icon on the serial cable
     (hover the cable to check). If that is Router3, set it there instead.

3. CONFIGURE OSPF

   Router0:
     router ospf 1
     router-id 10.2.2.2
     network 10.10.20.0 0.0.0.255 area 0
     network 192.168.0.0 0.0.0.255 area 0
     end
     wr

   Router1:
     router ospf 1
     router-id 10.1.1.1
     network 10.10.10.0 0.0.0.255 area 0
     network 192.168.0.0 0.0.0.255 area 0
     end
     wr

   Router2:
     router ospf 1
     router-id 10.3.3.3
     network 10.10.30.0 0.0.0.255 area 0
     network 172.16.0.0 0.0.0.3 area 0
     network 192.168.0.0 0.0.0.255 area 0
     end
     wr

   Router3:
     router ospf 1
     router-id 10.4.4.4
     network 10.10.40.0 0.0.0.255 area 0
     network 172.16.0.0 0.0.0.3 area 0
     end
     wr

   - Expect: %OSPF-5-ADJCHG ... from LOADING to FULL, Loading Done

4. CHECK CONNECTIVITY
   - On each router, at the Router# prompt:
       show ip route
   - O routes to the other loopbacks appear (shown as /32, which is normal)
   - Router0:
       ping 10.10.10.1
       ping 10.10.30.1
       ping 10.10.40.1
   - Router3:
       ping 10.10.30.1
       ping 10.10.20.1
   - !!!!! with 100 percent success means OSPF works
