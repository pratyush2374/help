PRACTICAL 8: Implement Inter-VLAN
=================================

IP PLAN (subnet mask 255.255.255.0 everywhere)
  PC0   VLAN 10   IP 192.168.10.2   Gateway 192.168.10.1   Switch Fa0/1
  PC1   VLAN 20   IP 192.168.20.2   Gateway 192.168.20.1   Switch Fa0/2
  PC2   VLAN 10   IP 192.168.10.3   Gateway 192.168.10.1   Switch Fa0/3
  PC3   VLAN 20   IP 192.168.20.3   Gateway 192.168.20.1   Switch Fa0/4
  Router0 Gig0/0 -> Switch0 Fa0/24 (trunk)
  Router sub-interfaces: Gig0/0.10 = 192.168.10.1, Gig0/0.20 = 192.168.20.1

1. BUILD THE TOPOLOGY
   - Routers -> drag 1 router 2911
   - Switches -> drag 1 switch 2960-24TT
   - End Devices -> drag 4 PC-PT
   - Connections -> Copper Straight-Through (solid black line)
   - Connect each PC (FastEthernet0) to the switch:
     PC0 -> Fa0/1, PC1 -> Fa0/2, PC2 -> Fa0/3, PC3 -> Fa0/4
   - Router0 (GigabitEthernet0/0) -> Switch0 (FastEthernet0/24)
   - Wait for the link dots to turn green

2. CONFIGURE THE SWITCH (Switch0 -> CLI tab -> press Enter)
     enable
     conf t
     vlan 10
     name sales
     exit
     vlan 20
     name market
     exit
     int fa0/1
     switchport mode access
     switchport access vlan 10
     exit
     int fa0/2
     switchport mode access
     switchport access vlan 20
     exit
     int fa0/3
     switchport mode access
     switchport access vlan 10
     exit
     int fa0/4
     switchport mode access
     switchport access vlan 20
     exit
     int fa0/24
     switchport mode trunk
     exit
     end
     show vlan brief
   - show vlan brief: VLAN 10 has Fa0/1, Fa0/3; VLAN 20 has Fa0/2, Fa0/4
   - Check the router is on Fa0/24: show cdp neighbors

3. CONFIGURE THE ROUTER
   - Click Router0 -> Config -> GigabitEthernet0/0 -> tick Port Status On
   - Router0 -> CLI tab -> press Enter
     enable
     configure terminal
     interface gigabitEthernet0/0
     no ip address
     no shutdown
     exit
     interface gigabitEthernet0/0.10
     encapsulation dot1Q 10
     ip address 192.168.10.1 255.255.255.0
     exit
     interface gigabitEthernet0/0.20
     encapsulation dot1Q 20
     ip address 192.168.20.1 255.255.255.0
     exit
     end
     write memory
   - show ip interface brief: Gig0/0.10 and Gig0/0.20 are up/up

4. SET THE PC IPs
   - Click PC0 -> Desktop -> IP Configuration -> Static
   - IP 192.168.10.2, mask 255.255.255.0, gateway 192.168.10.1
   - PC1: IP 192.168.20.2, mask 255.255.255.0, gateway 192.168.20.1
   - PC2: IP 192.168.10.3, mask 255.255.255.0, gateway 192.168.10.1
   - PC3: IP 192.168.20.3, mask 255.255.255.0, gateway 192.168.20.1

5. CHECK IT WORKS (test in this order)
   - Click PC0 -> Desktop -> Command Prompt
       ping 192.168.10.1     (its own VLAN gateway)
       ping 192.168.20.1     (the other VLAN's gateway)
       ping 192.168.20.2     (PC1, in the other VLAN)
   - First ping may time out, run it again; replies mean inter-VLAN routing works
