PRACTICAL 7: Implement GRE Tunnel
=================================

IP PLAN
  Router0   Gig0/0 1.1.1.1 (255.0.0.0)     Lo0 10.1.1.1 (255.255.255.0)   Tunnel1 192.168.13.1 (255.255.255.0)
  Router1   Gig0/0 1.1.1.2 (255.0.0.0)     Gig0/1 2.2.2.1 (255.0.0.0)     Lo0 20.1.1.1 (255.255.255.0)
            (hostname ISP)
  Router2   Gig0/1 2.2.2.2 (255.0.0.0)     Lo0 30.1.1.1 (255.255.255.0)   Tunnel1 192.168.13.3 (255.255.255.0)
  Tunnel: Router0 (source gig0/0, destination 2.2.2.2) <-> Router2 (source gig0/1, destination 1.1.1.1)

1. BUILD THE TOPOLOGY
   - Routers -> drag 3 routers of type 1941
   - Connections -> Copper Straight-Through (solid black line)
   - Router0 (GigabitEthernet0/0) -> Router1 (GigabitEthernet0/0)
   - Router1 (GigabitEthernet0/1) -> Router2 (GigabitEthernet0/1)
   - Wait for the link dots to turn green

2. CONFIGURE THE INTERFACES (router -> CLI tab -> press Enter)
   - If it asks "initial configuration dialog?", type: no

   Router0:
     enable
     conf t
     int gig0/0
     ip address 1.1.1.1 255.0.0.0
     no shut
     int lo 0
     ip add 10.1.1.1 255.255.255.0
     no shut
     exit

   Router1:
     enable
     conf t
     int gig0/0
     ip add 1.1.1.2 255.0.0.0
     no shut
     int gig0/1
     ip add 2.2.2.1 255.0.0.0
     no shut
     int lo 0
     ip add 20.1.1.1 255.255.255.0
     no shut
     exit
     hostname ISP

   Router2:
     enable
     conf t
     int gig0/1
     ip add 2.2.2.2 255.0.0.0
     no shut
     int lo 0
     ip add 30.1.1.1 255.255.255.0
     no shut
     exit

3. ADD THE STATIC ROUTES

   Router0:
     ip route 2.0.0.0 255.0.0.0 1.1.1.2

   Router2:
     ip route 1.0.0.0 255.0.0.0 2.2.2.1

4. CONFIGURE THE GRE TUNNEL

   Router0:
     interface tunnel 1
     tunnel source gig0/0
     tunnel destination 2.2.2.2
     ip add 192.168.13.1 255.255.255.0
     no shut
     end

   Router2:
     interface tunnel 1
     tunnel source gig0/1
     tunnel destination 1.1.1.1
     ip add 192.168.13.3 255.255.255.0
     no shut
     end

   - Expect: Line protocol on Interface Tunnel1, changed state to up

5. CHECK IT WORKS
   - Router0:
       ping 192.168.13.3
   - Router2:
       ping 192.168.13.1
   - !!!!! with 100 percent success means the tunnel works
     (first ping may show a few dots while the tunnel comes up, run it again)
   - Optional:
       show interfaces tunnel 1
     Tunnel1 is up, line protocol is up, source/destination as configured, GRE/IP
