PRACTICAL 6: Implement NAT (static NAT)
=======================================

IP PLAN
  PC0       IP 10.10.10.2   mask 255.0.0.0   Gateway 10.10.10.1   Public 50.50.50.2
  Server0   IP 10.10.10.3   mask 255.0.0.0   Gateway 10.10.10.1   Public 50.50.50.3
  PC1       IP 20.20.20.2   mask 255.0.0.0   Gateway 20.20.20.1   Public 60.60.60.2
  Router0   Fa0/0 10.10.10.1 (255.0.0.0)      Serial2/0 192.162.10.1 (255.255.255.0)
  Router1   Fa0/0 20.20.20.1 (255.0.0.0)      Serial2/0 192.162.10.2 (255.255.255.0)

1. BUILD THE TOPOLOGY
   - Routers -> drag 2 Router-PT
   - Switches -> drag 2 Switch-PT
   - End Devices -> drag 2 PC-PT and 1 Server-PT
   - Connections -> Automatic
   - Router0 -> Switch0 first (takes FastEthernet0/0), then Switch0 -> PC0, Switch0 -> Server0
   - Router1 -> Switch1 first (takes FastEthernet0/0), then Switch1 -> PC1
   - Connections -> Serial DCE (red zigzag) -> Router0 (Serial2/0), then Router1 (Serial2/0)
   - Wait for the link dots to turn green

2. SET THE END-DEVICE IPs
   - Click PC0 -> Desktop -> IP Configuration -> Static
   - IP 10.10.10.2, mask 255.0.0.0, gateway 10.10.10.1
   - Click Server0 -> Desktop -> IP Configuration
   - IP 10.10.10.3, mask 255.0.0.0, gateway 10.10.10.1
   - Click PC1 -> Desktop -> IP Configuration
   - IP 20.20.20.2, mask 255.0.0.0, gateway 20.20.20.1

3. SET THE ROUTER INTERFACE IPs (Config tab)
   - Click Router0 -> Config -> FastEthernet0/0
   - Port Status On, IPv4 Address 10.10.10.1, Subnet Mask 255.0.0.0
   - Serial2/0 -> Port Status On, IPv4 Address 192.162.10.1, Subnet Mask 255.255.255.0
   - Hover the serial cable to find the router with the clock icon
   - On that router's Serial2/0, set Clock Rate to 2000000
   - Click Router1 -> Config -> FastEthernet0/0
   - Port Status On, IPv4 Address 20.20.20.1, Subnet Mask 255.0.0.0
   - Serial2/0 -> Port Status On, IPv4 Address 192.162.10.2, Subnet Mask 255.255.255.0

4. CONFIGURE NAT (router -> CLI tab -> press Enter)
   - If it asks "initial configuration dialog?", type: no

   Router0:
     enable
     conf t
     ip nat inside source static 10.10.10.2 50.50.50.2
     ip nat inside source static 10.10.10.3 50.50.50.3
     int fa0/0
     ip nat inside
     exit
     int serial2/0
     ip nat outside
     exit

   Router1:
     enable
     conf t
     ip nat inside source static 20.20.20.2 60.60.60.2
     int fa0/0
     ip nat inside
     exit
     int serial2/0
     ip nat outside
     exit

5. ADD THE STATIC ROUTES

   Router0:
     ip route 60.0.0.0 255.0.0.0 192.162.10.2
     end

   Router1:
     ip route 50.0.0.0 255.0.0.0 192.162.10.1
     end

6. CHECK IT WORKS
   - On each router, at the Router# prompt:
       show ip route
       show ip nat translations
   - The S route appears, and translations list inside global <-> inside local
   - PC0 -> Desktop -> Command Prompt:
       ping 60.60.60.2     (replies; first ping may time out, run it again)
       ping 20.20.20.2     (fails: private address is not routed)
   - PC1 -> Desktop -> Command Prompt:
       ping 50.50.50.2     (replies)
       ping 10.10.10.2     (fails: private address is not routed)
   - Only the public (NAT) addresses are reachable across the link
